# Балтика 2.0 — Premium 3D Landing

Премиальный scroll-driven 3D-сайт для бренда «Балтика» с настоящей 3D-банкой Grapefruit.

**Live:** https://listok222.github.io/Balta-2.0/

## Особенности

- 3D-банка (GLB + fallback с реальной этикеткой)
- Банка плавает и движется по кривой при скролле (CatmullRom)
- Ледяные осколки с transmission / IOR
- Конденсат, particles, bloom
- GSAP ScrollTrigger
- Age-gate 18+
- Полностью адаптив + prefers-reduced-motion

## Структура

- `index.html` — разметка + age gate
- `css/styles.css` — ice aesthetic
- `js/main.js` — Three.js + GSAP
- `models/` — GLB и текстуры этикетки
