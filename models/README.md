# Models

Положи сюда файл `baltika_grapefruit_can.glb` из архива.

Как добавить:
1. Открой https://github.com/listok222/Balta-2.0
2. Перейди в папку models/
3. Нажми Add file → Upload files
4. Перетащи `baltika_grapefruit_can.glb`
5. Commit

После этого сайт автоматически загрузит настоящую 3D-банку.
